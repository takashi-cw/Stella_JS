# セキュリティポリシー

このリポジトリに関する脆弱性、秘密情報の露出、認証情報の漏えい、その他のセキュリティ上の問題を発見した場合は、公開Issueには投稿しないでください。

公開Issueに詳細を書くと、第三者がその情報を悪用できる可能性があります。

セキュリティに関する報告は、リポジトリの **Security** タブにある **Report a vulnerability** から、非公開で送信してください。

報告を確認したうえで、必要に応じて修正・無効化・削除・キーの再発行などの対応を行います。

---

# Security Policy

If you discover a vulnerability, exposed secret, leaked credential, or any other security issue related to this repository, please do not open a public issue.

Posting security details in a public issue may allow third parties to misuse the information.

Please report security issues privately using **Report a vulnerability** from the repository's **Security** tab.

After reviewing the report, I will take appropriate action as needed, such as fixing the issue, disabling or removing affected items, or rotating keys and credentials.Security Policy
